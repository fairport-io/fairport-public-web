Quick Start

Up and running in one command

Fairport installs as a single Helm chart. The installer handles all dependencies and configures everything automatically.

$ curl https://get.fairport.io | sudo bash -

Requires Linux with NVIDIA or AMD GPU drivers installed. See prerequisites before running.
