Getting Started

Up and running in three steps

No Kubernetes experience required. The installer handles RKE2, networking, and storage so you can focus on running models, not maintaining infrastructure.

1

Install the cluster

One command bootstraps RKE2, Cilium, and all prerequisites on your bare-metal or cloud nodes.

$ curl https://get.fairport.io | sudo bash -
2

Deploy the platform

A single Helm release installs GPU operators, the inference stack, monitoring, job scheduling, and more.

$ helm upgrade --install fairport \
  oci://gcr.io/fairport-io/fairport
3

Start building

Deploy models, submit training jobs, configure users, and connect your apps via the OpenAI-compatible API.

$ curl http://your-cluster/openai/v1/
